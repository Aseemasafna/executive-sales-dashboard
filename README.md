# Executive Sales Analytics Dashboard

An interactive Excel dashboard that analyzes sales performance across regions, categories, 
and customers, giving a CEO or Sales Manager the data needed to make informed decisions at a glance.



## Objective

Build a fully interactive sales analytics dashboard in Excel that consolidates ~10,000 
transaction records into clear KPIs, trends, and breakdowns — demonstrating end-to-end 
skills in data cleaning, formula-based analysis, PivotTables, and dashboard design.

## Dataset

Sample Superstore dataset sourced from Kaggle: [add your Kaggle dataset link here]
- ~10,000 order-level records
- Fields: Order ID, Order Date, Ship Date, Ship Mode, Customer ID, Segment, Region, 
  State, City, Category, Sub-Category, Product Name, Sales, Quantity, Discount, Profit

## Tools & Skills Used

- **Excel Online** — full workbook built and interactive dashboard designed in-browser
- **Data Cleaning** — manual deduplication, text standardization, missing value handling, 
  data type correction
- **Formulas** — XLOOKUP, SUMIFS, COUNTIFS, AVERAGEIFS, IF/IFERROR, TEXT, YEAR, MONTH, 
  EOMONTH
- **PivotTables** — 11 pivot tables covering monthly trends, regional/category breakdowns, 
  top products, top customers, and segment analysis
- **Slicers** — interactive filters by Region, Category, Segment, and Year, connected 
  across all pivot tables and charts
- **Data Visualization** — line, clustered column, bar, doughnut, and combo charts

## Key Insights

- West and East regions generated the highest sales, while South lagged behind.
- Furniture and Office Supplies together account for the majority of category sales.
- Sales peaked in November, with a secondary spike in September.
- The top 10 customers contribute approximately 7% of total revenue.
